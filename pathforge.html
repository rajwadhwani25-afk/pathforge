HOW IT WORKS

The backtracking algorithm starts at node 0 and extends the current path one vertex at a time. When it hits a dead end it backtracks and tries a different neighbor — repeating until a complete Hamiltonian path is found or all possibilities are exhausted.

Understanding Hamiltonian Paths

A visual, interactive guide to one of graph theory's most fascinating and computationally hard problems.

⬡ HAMILTONIAN PATH

A Hamiltonian Path visits every vertex exactly once. It doesn't need to return to the starting point.

Named after Sir William Rowan Hamilton who invented a puzzle on an icosahedron in 1857.

A → B → C → D → E (visits all once)

◎ HAMILTONIAN CIRCUIT

A Hamiltonian Circuit is a Hamiltonian path that returns to its starting vertex, forming a closed loop.

Every complete graph Kₙ (n ≥ 3) has one. It's the foundation of the Travelling Salesman Problem.

A → B → C → D → E → A

ORE'S THEOREM (1960)

If for every pair of non-adjacent vertices u and v with n vertices, deg(u) + deg(v) ≥ n, then G has a Hamiltonian circuit. This is a sufficient (not necessary) condition.

REAL-WORLD USES

Logistics routing, DNA sequencing, circuit board drilling, knight's tour on chess, scheduling, genome assembly.

WHY NO SOLUTION?

A vertex of degree 1 blocks circuits. Disconnected graphs have no path. Odd-degree vertex neighborhoods can create dead ends.

vs EULER PATH

Euler paths visit every edge once. Hamiltonian paths visit every vertex once. Very different algorithms!

NP-COMPLEXITY

No polynomial algorithm exists. Brute force is O(n!). Best exact: Held-Karp DP at O(2ⁿ·n²). Heuristics exist for approximations.
